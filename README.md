# Git flow:

```
1. Trước khi làm việc, pull nhánh dev về rồi mới làm
2. Tạo nhánh tên feature/ten-chuc-nang ứng với task của mình để làm việc trên đó.
3. Commit rõ ràng, có label: feat: ten-tinh-nang, fix: ten-loi, refactor: ten-tinh-nang, chore: linh-tinh
4. Hoàn thành tính năng nào thì PR vào nhánh dev.
```
